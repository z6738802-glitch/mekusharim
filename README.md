# מקושרים — בין הזמנים

מערכת הטבות טלפונית על גבי ימות המשיח. לקוחות מורשים מחייגים לקו, שומעים רשימת הטבות דינמית, ובוחרים הטבה (הרשמה או קופון) — הכל מנוהל דרך ממשק אינטרנטי.

## ארכיטקטורה

- **שרת** — Express (Node 20) על CapRover. שלוחת API אחת דינמית + admin API.
- **DB** — Postgres/Supabase, schema `mekusharim`.
- **ימות** — שלוחת `type=api` שפונה ל-`/ivr`. הקלטות קבועות בשלוחה הראשית, הקלטות שם הטבה בתיקיית `Benefits/`.

## מבנה הקו

1. בדיקת הרשאה (ApiPhone מול טבלת contacts)
2. שמיעת הטבות פעילות (דינמי)
3. בחירת הטבה
4. בדיקות: כבר בחר? מלאי? מגבלה למשפחה? ניתן לצבור?
5. ביצוע — הרשמה או הקצאת קופון (עם row locking)
6. אישור קולי

## הגדרת שלוחת ימות

```
type=api
api_link=https://<שרת>/ivr
```

## הפעלה מקומית

```bash
cp .env.example .env   # מלא ערכים
npm install
npm run dev
```

ממשק ניהול: `http://localhost:3000/panel`

## פריסה בקפרובר

Push לגיטהב → CapRover בונה מה-Dockerfile. יש להגדיר משתני סביבה באפליקציה (ראה `.env.example`).

## הערה על פורמט תשובות ימות

פורמט התשובות לשלוחת API (`read`, `id_list_message`) מרוכז ב-`server/services/yemot-response.js`. ייתכן שיצטרך כיוונון מדויק של סדר הפרמטרים ב-`read` מול מערכת חיה.
